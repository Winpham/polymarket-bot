# Forge Debates — Conditional / Coalition Consensus Engine (RUST)

Reality-checker + assembler record. Branch `feat/consensus-engine`, verified 2026-06-30.

## The two designs, compressed

**DESIGN_DIRECT (reuse-maximal).** "We own 90% of the machinery." Phases: P0 fix `(event,day)` clustering + wire slip/fee margin; P1 per-`(wallet,slice)` `SliceTrustMap` + add **3** EnrichCtx fields (`slice_trust`, `books`, `capture_margin`); P2 `arm_specialist` (rides `strict`) + `arm_smart_vs_dumb` (needs opposer identities via `books`); P3 `arm_edge_pool` fixed-weight log-odds pool; P4 `trader_slice_scores_asof` + walk-forward/null/holdout; P5 coalition mining. Certifies on the existing outcome scoreboard. Honest about the "few certified specialists → arms emit nothing" risk.

**DESIGN_RETHINK (dissolve the frame).** Two moves: (1) the unit is the FIRST lone certified-specialist footprint, not a crowd — fire early on `_blind` small/fresh books; (2) certify on **CLV line-movement** (`last−initial`), sd ~0.05–0.10 vs ~0.45 binary, ~5× tighter SE. One primary arm `spec_first_footprint` + one secondary `spec_contrarian`. Adds **one** EnrichCtx field (`slice_trust`). New CLV scoreboard with a `_blind` band-blind. Deliberately drops coalition mining. Names reflexive-CLV as the top risk.

## Key insights that emerged

1. **The binding constraint is specialist IDENTIFICATION, not the certification target.** Both A and RETHINK require ≥1 wallet that is gate-Trusted in a *sport* (≥30-event floor on a per-sport slice). With only 10/90 wallets clearing even the overall floor, per-sport certification is rarer still — so both arms likely emit ~nothing now. RETHINK's variance reduction helps the ARM gate clear *once a specialist fires*; it does **not** relax the specialist-identification floor. Neither design escapes this; honesty about it is the deliverable.
2. **CLV is a faster, lower-variance, label-free instrument — but it needs a blind population the system deliberately doesn't snapshot.** The right call is lens+guard, not certifier; the variance win is banked in reporting and in clearing the gate sooner once specialists exist.
3. **The minimal seam is genuinely one field.** Sport rides the signal; capture margin rides the gate; the contrarian needs no opposer book. EnrichCtx += `slice_trust` only.
4. **Conservatism direction matters.** `(event,day)` *raises* N — the only clustering "fix" on the table makes the gate weaker, not stronger. The instinct "more granular = more rigorous" is backwards here.
